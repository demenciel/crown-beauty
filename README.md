# Crown Beauty Bar: Gift Cards redesign

A static redesign of the [Crown Beauty Bar gift cards page](https://crownbeautybarsalon.com/gift-cards), built with plain HTML, CSS and JavaScript and no build step.

- `index.html`: page markup
- `styles.css`: brand tokens (black, blush pink, gold), layout and animations
- `script.js`: amount picker, card tilt, scroll reveals, mobile action bar
- `assets/img/`: the salon's own photos, resized

Open `index.html` in a browser to preview. Pushes to `main` deploy to GitHub Pages through `.github/workflows/pages.yml`.
